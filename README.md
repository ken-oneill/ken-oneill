## Hello there

I am a government statistician working for Social Security Scotland and Scottish Government. 

I lead Scottish Child Payment official statistics and help improve how statistics are produced through reproducible analytical pipelines (RAPs), open-source development and modern analytical practices.

A key area of interest is supporting colleagues to develop coding capability, adopt RAP principles and produce high-quality statistics in line with the Code of Practice for Statistics.

I also happen to be Deaf.

### Areas of focus

- Official statistics
- Scottish Child Payment statistics
- Reproducible analytical pipelines
- R programming
- Git and GitHub
- Statistical quality assurance
- Data governance and disclosure control
- Developing analytical capability.
